## What I bring to AI coding evaluation

My advantage is not just familiarity with developer tools. I can approach generated code as part of a working system: **Does it implement the requested behavior? Does it respect the data model and transaction semantics? Does it fail safely? Can its results be tested and explained?**

I am interested in coding-agent evaluation, code review, debugging, technical reasoning, and AI training work that benefits from practical software development and enterprise-system judgment.

## ERP experience is a differentiator, not the whole résumé

In ERP work, correctness is measured by business behavior: orders, inventory, accounting, fulfillment, controls, and operator experience. That context informs how I approach engineering and evaluate automated solutions.
